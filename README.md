# codex-trip

A lightweight starter repository scaffolded via the GitHub CLI.

## About

This project was bootstrapped with `gh repo create` and ships with a single
`README.md` to keep the layout minimal. Use it as a starting point for
whatever you're exploring next.

## Getting Started

```bash
git clone https://github.com/Lucapogg/codex-trip.git
cd codex-trip
```
